# Personal Expense Tracker 💰

A simple full-stack web application for managing personal income, expenses, and monthly budgets.

## 📌 Project Description

Personal Expense Tracker helps users manage their daily financial activities in one place. Users can create an account, log in, add income and expense transactions, edit or delete transactions, and set monthly budgets for different categories.

The application uses a Java backend connected to a MySQL database, with HTML, CSS, and JavaScript for the frontend.

## 🚀 Features

- User Signup and Login
- Add Income and Expense Transactions
- Edit Transactions
- Delete Transactions
- Transaction Search and Filtering
- Monthly Budget Management
- Edit and Delete Budgets
- Dashboard with Income, Expense and Balance
- Expense Overview
- Reports
- Dark Mode
- MySQL Database Integration
